# The Chill - Frigid

The Chill - Frigid upgrades the existing Winterhold jail "The Chill". Fresh cells are carved out in the back of the cave, opening up space for proper guards and supply storage. Guards will match the current civil war faction controlling Winterhold. Player inventory and stolen goods chests have also been added for the Winterhold crime faction.

Fully compatible with the "Beasts of Tamriel" dungeon "Frozen Underworld".

Only the "WinterholdJail" interior cell and "WinterholdJailExteriorNew" exterior cell are modified. This mod cannot be ESL flagged because it modifies base game objects, compacting form IDs breaks the mod.

## Installation

1. Navigate to C:/Program Files (x86)/Steam/SteamApps/common/Skyrim/ (or wherever you have Skyrim installed on your system).
2. Merge the Data folder from the mod’s zip file with the Data folder in the Skyrim directory.
3. Launch Skyrim and click on 'Data Files', then make sure the mod is enabled. Enjoy!
